# Security Policy

## Supported versions

This project is experimental. There is currently **no supported production release** and no security maintenance SLA.

## Reporting a vulnerability

Please avoid posting vulnerabilities, credentials, private file names, or account data in public issues. Use GitHub's private vulnerability reporting feature if available. Otherwise contact the repository owner through a private channel before disclosing details. Do not test against accounts or files you do not own.

## Safety limitations

The current alpha prototype has been demonstrated with a synthetic test folder on Fedora. It is **not approved for unattended syncing, automatic deletion, overwriting existing remote revisions, or unrelated accounts**. Back up any data independently and do not run the application on valuable personal files.
