# Contributing

Use **English for new documentation, source-code docstrings, comments explaining behavior, pull requests, and GitHub issues**. Keep UI translations localized for users. Do not rewrite signed-off historical test evidence solely to change its language.

Prefer small refactors with unchanged observable behavior, tests for failure modes, and scoped changes. Public contributions must not include account sessions, tokens, logs, private paths, real sync inventories, or production systemd configurations.

Before proposing a release, review `PUBLIC_ALPHA_READINESS.md` and `SECURITY.md`. This project is still experimental and not approved for unattended syncing.
